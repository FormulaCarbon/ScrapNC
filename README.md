# ScrapNC
Hobby CNC made from an old 3D-printer because I did not have the money for the big one.

<img width="734" height="754" alt="image" src="https://github.com/user-attachments/assets/e4de9629-7665-4768-a199-458a1a997a6e" />

Made using parts from a broken TAZ Pro 3D Printer. Most other parts can commonly be found in workshops as well, or 3D-printed. This CNC is meant to be as cheap as possible using parts that I already have.

Designed using knowledge gained from designing printNC and CindyMill-style machines, but much cheaper so I can actually get them fully funded by HackClub.

Features:
- 500w TRUE spindle (not a DC motor with a collet setscrewed on)
- ~ 8in x 10in x however tall you want working area
- Should be able to do Aluminum
- CNC Shield control system with DRV8825 for easy upgradability and low cost

Easy improvements:
- Add an RPi for wireless control and more features, such as a screen, physical controls, a camera, etc
- Add limit switches
- Upgrade to a proper CNC BOB
- Upgrade steppers
- Unified Control Panel

Build Guide and Instruction Manual will be added once I build and fix anything broken with the machine.
